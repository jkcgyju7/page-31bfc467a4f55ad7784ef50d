品牌简介

Tffy 是面向个人用户与小团队的网络加速品牌，核心能力是机场订阅与多协议客户端兼容。用户在官方网站完成套餐选择后，即可获得可持续更新的订阅地址，在 Clash、Shadowrocket、v2rayN 等工具中使用全球节点。

服务侧重点包括线路稳定性、流媒体可达性以及游戏场景的专线优化。旗舰与团队方案提供 IPLC 相关线路与更高并发设备数，基础方案则覆盖日常浏览与基础解锁。Tffy 官方下载指引只推荐正版客户端，避免来路不明的修改包造成订阅泄露。

作为 Tffy VPN 与 Tffy 机场的统一入口，本页同时说明套餐差异、操作步骤与常见问题，方便第一次使用机场服务的用户对照完成配置。

使用场景

跨境协作与远程办公

访问海外文档、代码仓库、会议与云控制台时，选择延迟较低的区域节点，可减少握手失败与页面超时。团队版支持更多设备同时在线，适合多人共用一条订阅。

流媒体与内容获取

基础版面向常规影视与音乐站点；旗舰版强调全节点原生解锁，更适合对地区库完整性要求较高的观看需求。连接后请先更新订阅再切换节点测试。

游戏加速与实时对战

游戏场景优先使用标注 IPLC 或游戏优化的线路，降低绕路带来的抖动。该能力在旗舰版中作为明确特性提供，实际效果仍取决于本地运营商与目标区服。

学术检索与开发调试

文献站点、镜像源与部分 API 调试可通过代理规则分流，不必全局接管系统流量。客户端中按域名或进程设置规则即可。

操作说明与配置流程

配置是使用 Tffy 的关键步骤。请按下列顺序操作，多数连接问题来自订阅未更新、客户端过旧或选错代理模式。

第一步：在官网完成订阅

进入套餐方案，按流量与设备数选择基础版、旗舰版或团队版。支付成功后，在用户中心复制 Clash 订阅或通用订阅链接，妥善保存，不要公开分享。

第二步：下载对应客户端

Windows 可使用 Clash Verge、v2rayN；macOS 可使用 ClashX Meta 或 Surge；iOS 常用 Shadowrocket、Stash；Android 常用 Clash Meta for Android。请通过应用商店或开发者发布页获取，Tffy 官方网站只提供选型说明，不以第三方安装包作为唯一来源。

第三步：导入订阅并更新节点

打开客户端的订阅或配置页面，粘贴 Tffy 订阅地址，命名后保存。务必执行一次「更新」以拉取最新节点列表。若列表为空，检查链接是否完整、是否被截断。

第四步：选择模式并连接

日常浏览可用规则模式（分流）；需要全局覆盖时再开 TUN 或系统代理。先选择邻近区域节点测试网页，再根据用途切换流媒体或 IPLC 线路。延迟高时不要反复狂点连接，等待握手完成后再测速。

第五步：验证与日常维护

打开目标站点或进行短时游戏对局确认可用性。之后保持客户端自动更新订阅，系统或应用升级后如出现无法联网，优先检查代理开关与 TAP/TUN 权限。设备数量请控制在套餐额度内。

完成以上配置流程后，即可把 Tffy 机场当作长期可用的加速入口。后续只需按月或按年续费，不必重复安装。

常见问题

Tffy 机场和 Tffy VPN 有什么区别？

Tffy 以机场订阅为主，提供可切换的多区域节点；在客户端里也可按 VPN 方式一键全局连接。同一套餐同时覆盖这两种用法，不必重复购买。

第一次使用应该怎样完成配置？

先购买套餐拿到订阅链接，再安装正版客户端，粘贴订阅并更新节点，最后用规则模式连接邻近节点验证。详细步骤见本页「操作说明与配置流程」。

官方支持哪些系统与客户端？

Windows、macOS、Android、iOS 与 Linux 的主流代理工具均可导入 Tffy 订阅。推荐具备自动更新订阅能力的 Clash 系、Shadowrocket、v2rayN 等，具体以各应用兼容协议为准。

流量和设备数量如何计算？

基础版每月 100GB、3 台同时在线；旗舰版 300GB、5 台；团队版 1000GB、20 台。流量按套餐周期重置，设备按并发连接统计，长时间挂机也会占用名额。

能否解锁常见流媒体？游戏延迟如何？

基础版提供基础流媒体能力；旗舰版与团队版强调全节点原生解锁。游戏请优先选择 IPLC 或游戏优化线路，实际延迟仍受本地网络与目标服务器影响。

连接失败或速度不稳定怎么处理？

依次尝试：更新订阅、更换节点、切换规则/全局模式、检查系统时间与客户端权限。旗舰版用户可通过优先工单反馈线路问题，团队版另有客户经理通道。

客户端应该从哪里下载才安全？

请使用应用商店或开发者官方发布渠道。Tffy 官网提供选型与导入说明，不把第三方修改包当作官方下载。任何要求你交出订阅链接的「代配置」都应拒绝。
